# شركة الذهب الملكي - Royal Gold Company

موقع إلكتروني لشركة ذهب مبني بـ PHP مع تصميم احترافي بألوان ذهبية.

## المميزات

- تصميم عصري ومتجاوب (Responsive) يعمل على جميع الأجهزة
- صفحة رئيسية مع عرض أسعار الذهب والمنتجات المميزة
- صفحة "من نحن" مع قصة الشركة والرؤية والرسالة
- صفحة المنتجات مع فلتر حسب النوع
- صفحة اتصل بنا مع فورم تواصل
- تأثيرات حركية (Animations) عند التمرير
- قائمة تنقل متجاوبة للموبايل

## هيكل المشروع

```
gold-company-website/
├── index.php                 # الصفحة الرئيسية
├── includes/
│   ├── header.php           # الهيدر والنافيجيشن
│   └── footer.php           # الفوتر
├── pages/
│   ├── about.php            # صفحة من نحن
│   ├── products.php         # صفحة المنتجات
│   └── contact.php          # صفحة اتصل بنا
├── assets/
│   ├── css/
│   │   └── style.css        # ملف الاستايل
│   ├── js/
│   │   └── main.js          # ملف الجافاسكريبت
│   └── images/              # مجلد الصور
└── README.md
```

## التشغيل

### باستخدام PHP المدمج
```bash
php -S localhost:8000
```

### باستخدام XAMPP / WAMP
انسخ المشروع إلى مجلد `htdocs` وافتح `http://localhost/gold-company-website`

## التقنيات المستخدمة

- **PHP** - لغة البرمجة الخلفية
- **HTML5 & CSS3** - هيكلة وتنسيق الصفحات
- **JavaScript** - التفاعلات والتأثيرات
- **Font Awesome** - الأيقونات
- **Google Fonts (Cairo)** - الخط العربي
